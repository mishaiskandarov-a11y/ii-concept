# Internet Identity — UI concept

A temporary, static build of the redesign concept, running on mock data.

Open: https://mishaiskandarov-a11y.github.io/ii-concept/

This repo holds build output only. To update it, rebuild the concept from the
source branch (`II_CONCEPT=1 npx vite build --config vite.concept.config.ts`),
copy `concept.html`, `favicon.svg` and `_app/` here, and push.
